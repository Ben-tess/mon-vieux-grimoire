# Mon vieux Grimoire


## Comment lancer le projet ? 

### Avec npm

Faites la commande `npm install` pour installer les dépendances puis `npm start` pour lancer le projet. 

Le projet a été testé sur node 19. 

### Un fois le projet installé

Ouvir un terminal pour le backend puis un autre pour le frontend

Faites la commande `npm start` d'abord dans le terminal backend puis dans le terminal frontend pour lancer le projet.
